1. Environment Variables & Key Supply

This application relies on Google Gemini 2.5 Flash for planning and execution. API keys can be supplied via two pathways:

Pathway A: Per-Session Custom Key (UI Settings Panel)

Click Settings in the main header and paste your key. It is held strictly in browser memory for the active session, passed via the X-Gemini-Api-Key HTTP header, and never written to disk or logs.

Pathway B: Server-Wide Default Environment Variable

Set GEMINI_API_KEY in a local .env file or server environment configuration:

# Local .env Configuration
GEMINI_API_KEY=AIzaSyYourActualApiKeyHere
PORT=8000
TESSERACT_CMD=C:\Program Files\Tesseract-OCR\tesseract.exe  # Windows local dev only
Variable / Header Location Description
X-Gemini-Api-Key HTTP Header Per-user key sent with /session and /reply requests. Overrides server default.
GEMINI_API_KEY Server .env Default fallback key for the server. Required if users don't supply a custom key.
TESSERACT_CMD Windows only Path to tesseract.exe. Linux/Docker uses system package automatically.
PORT Environment Server port (defaults to 8000; Render injects this dynamically).

Get a free Gemini API Key from Google AI Studio.

2. Deploying on Render (Free Tier)

The repository includes a production Dockerfile pre-configured with Linux system packages (Tesseract OCR, FFmpeg) and a pre-cached faster-whisper AI audio model.

  1. Push Code to GitHub: Ensure all code is committed and pushed to your repository.
  2. Create Web Service on Render: Go to Render Dashboard → New + → Web Service and select your repository.
  3. Configure Environment: Set Runtime to Docker (Render auto-detects the Dockerfile).
  4. Select Instance Type: Choose Free (512 MB RAM). *(Fits our ~350 MB peak int8 Whisper + OCR memory budget per Decisions 2, 5 & 12)*.
  5. Set Environment Variables: Add GEMINI_API_KEY under Environment Variables.
  6. Deploy: Click Create Web Service. Render automatically builds the container and binds to $PORT.

Verify deployment liveness: visit https://<your-app>.onrender.com/health. Expected output: {"status":"healthy","gemini_configured":true}.

3. Local Docker Command

To test the container locally using Docker:

docker build -t multimodal-agent .
docker run -p 8000:8000 -e GEMINI_API_KEY=your_key_here multimodal-agent

4. Testing & Verification

Run the full automated test suite using pytest:

python -m pytest -v --cov=app --cov-report=term-missing
